# All Competency Questions

[Overview](README.md)

All **67** competency questions of the four use cases in one table. Identical questions asked by different personas are merged into one row, which lists all their IDs (persona ID + CQ number). Each ID links to the persona section, where the goal, research scenario, user stories, and notes can be found.

TP WGM: *Themenportal Wiedergutmachung* · BZK KG: *BZK Knowledge Graph*

**Category** refers to the three [CQ categories](README.md#cq-categories): **1** = queries answerable through TP WGM · **2** = queries over the complete BZK KG · **3** = data provenance and processing queries. **Knowledge gap** marks questions that cannot be answered based on the BZK cards or the BZK KG.

Note: **SPARQL queries** will be added once the BZK KG has been generated.
